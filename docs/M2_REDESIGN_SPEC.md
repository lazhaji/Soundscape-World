## 1. 已确认的完整目标

### 胶囊（已确认，最终版本待整合）

- 首屏为行驶中的靠窗视角与底部单个胶囊；正常状态移除旧营销文字、品牌/目的地/页脚。真实错误可临时出现，Demo 标识保留在声音/车站信息中。
- 七种互斥选择：专注、睡眠、勿扰、平静、愉悦、焦虑、孤独。首次默认平静，此后预选上次确认值；临时选择不保存、不改当前播放策略。
- 底部居中约 260×88 CSS px，加安全区。同一胶囊向上连续展开为七个纵向选项；长按 **600ms** 后滑到选项、松手选择收起；未刻意移向选项或松在空白处则取消本次选择。
- 展开符号可以点击：点开后保持，点击一项选择收起；左箭头只作提示。点击外部/Escape 收起时保留打开前的草稿。
- 胶囊整体左拖约宽度 40%（260px 时约 104px）并松手确认。未达阈值/松手前拖回则回弹；早期明确左拖锁定滑动，展开后同一手势只选择、不启程。系统取消或后台中断手势时取消本次操作。
- 短屏保持长按拖选，限制列表高度并在边缘自动滚动。另有屏幕阅读器可访问、键盘聚焦时显示的「确认并启程」辅助入口。
- 材质严格沿用 gentpan/liquidglass 默认 clear：收起 button、展开 panel、白字、真实折射动态车厢。文字保持清楚。点击/按压形变、系统减少动态/减少透明度/高对比按已讨论规则处理。
- 优先在既有 renderer 内适配上游镜片映射与 shader；上游 WebGL 版缺少 panel blur，需要适配，不能假称已经同等。先降低折射渲染分辨率，失败/过慢允许上游磨砂回退，但不算真实折射验收通过。
- 仅复制所需上游内容并保留许可，不引入整套示例。真实 iPhone Safari / Android Chrome 必须另行验收。

### 策略、保存和失败处理（目标，非本轮已实现的新存储）

- 专注/睡眠/勿扰禁社交；其余仅允许未来显式开启，本轮没有社交功能。
- 睡眠无旋律，按天气播放环境声；七种选择均保留广播。其他选择沿用现有原创器乐，焦虑模式增益 0.65，其他为 1；用户音量不被覆盖。
- 旧设置迁移优先级：sleep → sleep，focus → focus，再 DND → dnd，否则四种同名心情沿用，tired → calm。只在确认时写入；不清空数据库。
- 设置读取完成前不能确认；2.5 秒超时提示后可继续；迟到恢复不覆盖已操作草稿。场景未就绪时可选但不能出发；失败保留选择可重试。
- 确认手势内解锁音频；保存异步执行，失败明确告知当前选择未保存。音频启用失败仍可静音到站。
- 返回列车保留当前声音播放/暂停状态；下一次确认可启声。音频引擎独立于 UI/Canvas。

## 2. 本轮确认的列车与天气

| 分支 | 最终决定 |
|---|---|
| 29–34 | 靠窗开场；确认后边转向侧窗边减速；停稳后镜头穿玻璃，升高时人物从车门下车；到 45° 时人物已在站外；便利店为主、列车/站台在边缘；下车后列车驶离 |
| 35–38 | 晴天、多云、小雨 × 白天、黄昏、夜晚；首次和每次返程抽取下一趟条件；同一趟行驶/到站/店内保持一致；睡眠无旋律，环境声跟随天气 |
| 39–41 | 镜头固定时列车正在驶离，随后出画；返回列车展示下一班进站和登车；轨道斜向延伸 |
| 42–47 | 返回时自动从当前位置走站台，暂停点地面；下一班同步接近，等待人物上车；镜头下降穿侧窗回座位；到站目标 7–8 秒，再约 3 秒驶离；返程原天气保持到发车后，用窗外遮挡切换；轨道画面左侧、店在中右 |
| 48–49 | 有减速/开关门/驶离声音及广播；返程完整播放，无跳过 |
| 50–57 | 行驶中也定期广播；日文；七种选择均有；无字幕；返程目标 10–12 秒，远处走路可延长；后台冻结、前台画面自动继续，声音手动恢复，过期广播不补；减少动态效果保留关键事件但改固定视角/短叠化；去程同样无跳过 |
| 58–61 | 行驶每 30–45 秒播报；人声温和清楚，播报时适当压低列车声；由 Codex 查找制作途径，但先做 Demo；通用日文文案，不报站名 |

相机穿窗不代表人物穿窗。本站列车尚未离开时，返程先等待它离开，之后下一班进站。场景是有限的便利店底座，不提供自由镜头、摇杆或开放世界。

## 3. 本轮 Demo 实现

- 入口：`#/demo/train`；正式入口底部提供链接。正式入口与 M1 调试页原流程保留。
- 原创占位车厢内外模型、真实侧窗开口、独立滑门、车头、移动林地、站台和轨道。复用 M1 商店和寻路；商店视觉接受可选 simulation，默认仍用原实例。
- 纯 `TrainDemoController` 按有效前台帧推进；正常去程 8 秒到站，列车约 11 秒完全离场。普通返程最短约 11.7 秒；若上一班未离场/人物还在走路则延长。
- 同一 PerspectiveCamera 连续运镜，最终 **36° FOV、视线俯角严格 45°**，按横竖屏调整距离。Demo 使用低畸变透视而非声称正交；最终投影效果待用户观看。
- 人物下车与镜头分离；固定镜头后地面点选、进店、屋顶剖面与返程有效。登车段为有限的预设路径，不提供轨道自由行走。
- 天气/时段独立随机，返回穿窗后以窗外隔音屏遮挡切换天气并重置车厢相对坐标，避免在可见站台突变。
- 所有声音沿用同一个应用级 AudioEngine。新增原创风纹理、短机械门声、距离/运动混音；更换天气时交叉淡化并释放旧天气音源，不重启音乐。暂停/后台丢弃未完成的短音效。
- 临时七选一原生选择控件，确认映射到旧引擎策略，仅供 Demo；**未实现最终胶囊、七选一持久化和旧设置迁移**。不覆盖正式入口的 IndexedDB 值。
- **日文广播尚无音频**，页面明确标注待接入。只有事件与 30–45 秒调度，不冒充已有可听广播；人声混音/压低底噪尚未验收。
