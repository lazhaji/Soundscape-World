# 决策记录：当前方案优先于旧构想

| 编号 | 最终选择 | 取消或暂缓的旧方案 |
|---|---|---|
| D01 | 手机 Web / PWA，静态托管、本地数据 | 小程序、原生 App 优先 |
| D02 | 无自建后端、云数据库、项目账户或云端社交；默认无需账户、不连接云服务 | 项目注册/登录/在线陌生人发现；可选第三方文件存储授权仅按 D16–D20 开启 |
| D03 | 不使用 AI；规则推荐 + 模拟旅人 | 小模型/AI 生成聊天 |
| D04 | Loading 后在行驶中新干线面向门；液态玻璃选择 | 进入普通音乐 App 列表首页 |
| D05 | 车站是固定 45° 微缩便利店场景 | 旧版第三人称开放世界与俯瞰大地图 |
| D06 | 点击地面移动角色，屋顶可剖面 | 常态自由旋转模型和自由镜头 |
| D07 | 进店音乐、出店雨声 + 偶发过车 | 室外持续听主音乐 |
| D08 | 社交雷达在列车上主动进入 | 打开页面/便利店中强制社交弹窗 |
| D09 | 专注/睡眠/勿扰业务层禁用社交 | 只隐藏按钮 |
| D10 | 模拟旅人可搭列车到不同店铺 | 无后端的真实在线雷达 |
| D11 | 预置脚本、3分钟临时聊天，不持久化 | 云聊天、AI 聊天、消息永存 |
| D12 | 周/月/年本地声音档案 | 在线人格分析 |
| D13 | 有许可证的音频 + 本地导入 + 白噪音 | 未授权网易云/Spotify 曲库抓取 |
| D14 | 优先可玩的程序性 3D，再替换高质量 GLB | 把概念图当作 3D 模型 |
| D15 | 不接管系统熄屏显示 | iOS Live Activity / 原生锁屏 |
| D16 | 本地优先跨设备声音档案；IndexedDB 为唯一的本地业务数据源；M4 先做版本化 JSON 导入/导出 | 远端文件直接成为业务数据源；提前实现云同步或改变 M1 优先级 |
| D17 | 所有同步业务记录/事件保留稳定唯一 ID；事件合并、去重、会话修订与冲突处理后复算统计 | 每次导入生成新 ID、统计快照相加、最后上传文件覆盖全部历史 |
| D18 | 后续采用 SyncProvider；优先评估 Dropbox 官方 JavaScript SDK、OAuth 2.0 PKCE、App Folder 最小权限；WebDAV 为检查 HTTPS/身份验证/CORS 后的高级选项 | 绑定单一存储商、全盘权限、浏览器内嵌客户端秘密、自建跨域代理 |
| D19 | 云同步默认关闭，用户主动开启并了解第三方存储隐私边界；不传本地音乐文件、临时聊天、授权令牌 | 默认上传、隐式连接、凭据混入备份；断开即声称远端文件已删除 |
| D20 | 后续评估 Web Crypto API 客户端加密；仅保证网页运行期间适时同步 | 未实现即声称已加密；承诺浏览器关闭后持续后台同步 |

2026-10-09：D16–D20 为需求与架构决策，云同步尚未实现、适配器与加密尚未验证；M4 手动 JSON 备份先行，云同步另行授权排期。继续优先完善和验收 M1 便利店及室内外音频系统。
