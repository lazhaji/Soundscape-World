2026-10-09：D16–D20 为需求与架构决策，云同步尚未实现、适配器与加密尚未验证；M4 手动 JSON 备份先行，云同步另行授权排期。继续优先完善和验收 M1 便利店及室内外音频系统。

参考视频：`references/liquid_glass_reference.mp4` 用于玻璃 UI 质感。用户此前上传的开放世界视频只属于**已否决的旧探索方向**，不要据此重建开放世界。

可调整的默认值：模式时长、音量渐变毫秒数、镜头方位、NPC 名称、音乐匹配权重，均集中配置。

## M2 落地补充（2026-10-09）

- 用户明确确认 M1 验收成功并开始 M2，取代旧 HANDOFF 中等待 M1 收尾确认的状态；真机/长期性能未实测仍如实保留。
- 主入口为全屏列车到便利店，原 M1 验证页保留在 `#/debug/m1`；不创建开放世界。到站切换独立构图并上摇至固定正交视角。
- M2 设置复用即使用 IndexedDB，仅存 mode/mood/doNotDisturb；M4 再扩展档案与迁移，遵守唯一业务存储源，不临时引入 localStorage。
- M2 只对现有原创器乐做模式适用过滤；睡眠无适用曲目时明确回退纯雨声，心情为疲惫/焦虑时柔化音乐。完整曲库、评分、定时器留给 M3。
- 社交权限纯函数本轮建立且测试，但雷达和聊天仍未实现；不以可点击的假功能掩饰后续里程碑。

## M2 模式弹窗重设计（2026-10-10）

- 用户指定 liquid-glass-frontend / liquid-glass-web 并明确要求重新设计模式弹窗；本轮限于 M2 视觉与交互，没有提前实现 M3 播放器。
- 面板 CSS 磨砂、勿扰手柄局部真实折射；不在 Three.js 背景上新增全屏折射渲染。复用原生控件和既有 GlassDialog，不引入整套 Web Components、Motion 或框架迁移。
- 只本地复制 MIT 核心 v1.0.0，保留许可、来源与哈希；懒加载失败为无损装饰降级。不要把核心的上游三引擎验证等同于当前项目在三引擎实测。
- 模式、心情、勿扰的业务规则与 IndexedDB 保存契约不变；取消不保存，仅确认后进入到站流程。

- 用户逐项确认的七种互斥选择、胶囊交互、往返运镜、随机天气、日文广播见 [M2_REDESIGN_SPEC.md](M2_REDESIGN_SPEC.md)。这是当前新目标；10-10 的面板规则仍描述现有正式入口，不再作为下一版交互目标。
- 用户最后明确「60B 先做 demo」。本轮增加独立 `#/demo/train`，先验靠窗→侧窗→45°、列车驶离与下一班返程；正式入口的胶囊、持久化迁移尚未整合。
- 去程与返程均无跳过；减少动态效果保留事件顺序，以固定画面/短叠化替代大运镜。后台冻结，回前台画面继续，声音仍由手势恢复；过期人声不补播。
- 广播为日文，无字幕，七种选择均保留；行驶中每 30–45 秒一次，关键节点优先。当前只有调度、文案和制作候选，音频未接入；不以字幕/假按钮冒充。
