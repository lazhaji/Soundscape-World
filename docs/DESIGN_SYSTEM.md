# Soundscape Railway — 视觉与交互规范

## 美术目标

- 日式三渲二雨夜，**冷蓝户外 + 暖黄便利店内部**。方形可见底座、紧凑可读的便利店陈设，绝不追求无限地图。
- 正交相机/低畸变固定约 45° 俯视；雨丝、屋檐滴水、涟漪、灯箱柔和微闪、窗面雨痕、路面湿反射与店内货架/关东煮/冰柜/收银台。
- 参考 `../references/store_concept.png` 是静态视觉目标图；Codex 应先用程序化几何占位，不得声称已经还原为 3D GLB。
- 新干线只建造一小段车厢近景，透过移动窗外景物表现速度，轻晃并用音频配合停车。

## 液态玻璃

参考 `../references/liquid_glass_reference.mp4`。阶段一用 CSS `backdrop-filter: blur(16–24px)` + 半透明渐变 + 内高光 + 1px 描边 + Motion 弹簧缩放和圆角变化；高性能阶段可选 SVG/WebGL 局部折射，但手机实机帧率优先。模态必须可关闭，支持键鼠焦点和手机点击区。

## 关键动画（设计起点）

| 动作 | 建议区间 |
|---|---|
| 车厢淡入 | 400–800ms |
| 液态模式面板展开 | 350–500ms |
| 列车减速、开门、下车、镜头上摇 | 2–5s，可按资源加载调整 |
| 进/出店时建筑剖面与音景过渡 | 500–1200ms |
| 雷达结果展开 | 300–800ms |
| 身份卡变聊天窗口 | 350–600ms |
| 临时聊天退出消散 | 300–500ms |

## 移动交互与性能

- 竖屏主导，常态尽量无 UI，最小可用交互点清晰；低优先控件放在玻璃 HUD。
- 点击地面移动微缩角色，店门自动开合；不引入自由镜头/摇杆探索。
- 手机软键盘与 `safe-area-inset-bottom` 适配；不让输入框被遮挡。
- 支持 `prefers-reduced-motion`，无需频闪；音量轻柔，音效避免削波和突发大音量。
- 先保证可读性和 30fps，再考虑高级雨水 Shader 和实时折射；画质档覆盖 low/medium/high。
