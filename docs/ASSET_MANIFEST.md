## 将来添加音频、3D、贴图时必须填写

- `assetId`、路径、类型、作者、原始来源链接、许可证名称、取得日期、是否需要署名、是否允许修改、是否允许网页再分发、署名文案。
- 自己程序化创建的模型/音效注明「项目原创」；尚未确定许可的曲目**不得纳入发布包**。
- 第三方模型若带品牌标识需检查授权；正式便利店招牌优先原创虚构品牌。

## 美术工作顺序

1. 可跑的程序化模型：方形底座、玻璃门、屋顶、货架、道路及角色。
2. 先打通角色进出店和区域音景。
3. 再用 Blender / 合规 GLB 加入冰柜、关东煮、细节陈设。
4. 最后完成屋檐滴水、雨窗、涟漪、湿地反射、灯光优化。
