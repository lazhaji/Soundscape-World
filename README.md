# Soundscape Railway

移动端声音空间个人作品集。M0/M1/M2 已由用户验收；当前 **M3 播放器、设备曲库、本地导入、规则推荐和定时器已实现，待用户验收**。主体验为新干线靠窗 → 七状态玻璃控件 → 自动到站 → 固定45°便利店 → 返回列车。

程序化模型与内置音源均明确标为原创 Demo。无后端、账户、云数据库或 AI。需求以 [PRD](docs/PRD.md) 为准；新 Session 先读 [HANDOFF](docs/HANDOFF.md)，当前交付见 [M3_REPORT](docs/M3_REPORT.md)。

## 本地运行

Node.js 22.13+（22.x）或24.x；使用现有精确依赖与lockfile。

```bash
npm ci
npm run dev
```

打开终端给出的本机地址：

1. 首次静音，画面只有列车和一个状态矩形。长按600ms展开七状态；选中后，仅将左侧圆形图标向右拖至有效行程85%并松开确认。键盘长按空格展开、选择后长按右方向键并松开。
2. 自动到站后点地面行走；进店音乐渐入，出店精确静音且进度继续。睡眠只选无旋律噪音，焦虑状态降低音乐模式增益。
3. 站内「声音」打开播放器，可暂停、下一曲、喜欢/跳过、独立调音乐与环境音量；曲库和定时器折叠在面板内。关闭面板不会重置播放或定时。
4. 内置原创《雨灯》、白/粉红噪音 Demo；本地导入需本人有权使用，单首≤10MiB/5分钟，最多20首/100MiB。保存在当前浏览器，刷新保留；删除仅删设备副本，浏览器清站点数据可能丢失。
5. 专注默认25分钟关闭音乐，睡眠默认30分钟淡出全部；支持预设和1–180分钟自定义，可取消。关面板不影响截止，后台恢复按绝对时间校正；锁屏瞬时停止无法保证。刷新取消本次定时并回到静音。
6. 「返回列车」完成返程后可以重新选择状态；同页共用唯一音频引擎。M2 模式设置、M3曲库和喜欢/跳过通过 IndexedDB 保存。

当前主入口与 `#/demo/train` 共用同一实现；`#/debug/m1` 保留空间验证页。普通根入口尊重系统减少动态偏好；`?motion=full` 明确启用完整场景运镜/窗景，玻璃仍尊重系统减少动态偏好。

手机联调可运行 `npm run dev -- --host 0.0.0.0 --port 4181`，同网段访问电脑IP；**导入和偏好保存需要HTTPS安全上下文或浏览器本机localhost**，普通手机HTTP局域网地址会明确提示限制。正式静态托管需HTTPS；本轮未部署。真机听感/锁屏/GPU仍待手工验收。

## 源码与数据

- `src/demo/train/`：当前主体验、纯时序与运镜、随机天气/时段、场景声音协调。
- `src/world/`：复用便利店、固定镜头、角色、寻路、坐标判区与M1调试。
- `src/audio/`：单例引擎、分层增益、目录、推荐、导入校验、应用级播放器与定时。
- `src/db/`：原生IndexedDB `soundscape-db` v2；保留settings/mode，新增tracks/feedback。后续迁移不能清库。
- `src/ui/`：已验收的官方玻璃状态控件、声音播放器、可访问弹窗和错误边界。
- `tests/unit/`、`tests/integration/`：业务与音频回归；一次性浏览器脚本/截图在忽略目录`output/playwright/`。
