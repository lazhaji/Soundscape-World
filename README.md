# Soundscape Railway

移动端声音空间个人作品集。产品需求以 [`docs/PRD.md`](docs/PRD.md) 为首要依据。

当前实现 **M1：可交互的微缩便利店与空间音景**。在固定约 45° 正交视角下，点击地面让角色自动行走；角色从自动门进店时，屋顶与遮挡墙淡出，音乐渐入、雨声减弱；出店后音乐淡至 0，但同一音轨的播放时间继续前进。场景、角色和音景均为明确标注的原创程序化 Demo。

## 本地运行

需要 Node.js 22.13+（22.x）或 24.x；本轮环境为 Node.js 24.12.0 / npm 11.6.2。直接依赖使用精确版本，完整依赖树由 `package-lock.json` 锁定。TypeScript 固定 5.9.3，以满足当前 TypeScript ESLint 的兼容范围。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:5173`）：

1. 初次打开，角色在店外，音频保持静音。
2. 调低设备音量，点击「点击启声」，在店外听合成雨声。
3. 点选店内地面（屋顶也可透过点选其下方地面），或用「走进店内」快捷目的地；角色会绕开墙和家具、从门口进店。门自动打开，屋顶/遮挡墙淡出；音乐渐入。
4. 点门口或使用「停在门口」，验证中间混音状态；点外部空地或「回到店外」，音乐在 0.8 秒内渐至静音，进度继续。
5. 连续进出 10 次；观察旋律保持连续，不因区域改变或「重载场景」从头播放。
6. 「暂停声音」冻结音频时间，角色仍能走动；点击「继续聆听」从原进度按当前区域继续。音乐/雨声音量独立于区域增益。

切到后台会暂停声音与场景更新；回到前台需点击继续，避免平台自动恢复失败或意外出声。刷新是一次新会话：回到店外、进度归零、等待手势，无播放状态持久化。

手机联调可运行 `npm run dev -- --host 0.0.0.0`，在同一局域网访问电脑 IP 和终端端口。允许防火墙访问时只开放所需的本地开发端口。这里的手机步骤需要实际设备执行，不等同于桌面移动模拟。

## 检查与构建

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npm run preview
```

`build` 先检查类型，再输出 `dist/` 静态文件；`preview` 默认使用 `http://127.0.0.1:4173`。资源路径采用相对 base，便于以后部署到子目录。直接双击 HTML 不属于支持的运行方式。

Vitest 单元/集成测试覆盖寻路碰撞、门槛滞回、增益渐变、10 次往返、手势启动、暂停/取消/重试、浏览器中断、资源释放与原创 PCM。浏览器记录和实机步骤见 [`docs/TEST_PLAN.md`](docs/TEST_PLAN.md)。

本地预览地址为 `http://127.0.0.1:4173/`；服务关闭或重启电脑后，运行 `npm run build`、`npm run preview` 并保持终端打开即可恢复。这是当前电脑的本地地址，手机应使用同网段电脑 IP。

## M1 源码结构

- `src/app/`：页面、全局世界模型与页面生命周期绑定。
- `src/world/`：共享布局、纯函数寻路/区域检测、移动模拟、可替换模型、固定相机、加载/重试。
- `src/audio/`：应用级 AudioEngine、独立通道增益、32 秒原创旋律与循环雨声生成；区域变化只调整音量。
- `src/ui/`：基础音景控制、进度与错误边界。
- `tests/unit/`、`tests/integration/`：音频、寻路与真实位置驱动混音测试。
- `public/`：项目原创图标；参考 PNG/MP4 不会打入发布包。

## 已知边界

- 目前是简化 3D 美术：完整实现移动、自动门、屋顶/遮挡墙剖面与三个声音区域；正式 GLB、雨夜 Shader、真实录音、随机过车音效尚未加入。
- 声音启动与 WebGL 失败有提示；启声等待最多 10 秒，3D 初始化最多 12 秒。后台主动暂停，无法保证锁屏播放。
- 3D 前台运行渲染循环，后台停帧，DPR 1–1.5；reduced-motion 关闭角色步态摆动和 CSS 过渡。真实手机 GPU、听感与 Safari 兼容性仍需实测。
- 尚无 Service Worker、离线缓存、数据库或持久化功能。后续只能按里程碑推进。
- 当前已有 Git 仓库；M1 修改保留在工作区，本轮没有创建提交或修改远程仓库配置。
- 当前 3D 按需模块约 920 KB（gzip 244 KB），仍有 Vite 的 500 KB 警告。R3F 9.8.1 内部使用 `THREE.Clock`，在 Three.js 0.186.1 中产生弃用警告；已验证的正常交互无应用错误。

## 项目资料与后续开发

1. 将本资料包解压到你准备作为 `soundscape-railway` 的项目仓库根目录。
2. 若已存在源码：复制并合并文档与参考素材，谨慎处理同名文件，勿覆盖已有代码或 `AGENTS.md` 的有效规则。
3. 在 Codex 中打开这个仓库。
4. `CODEX_START.md` 保留为 M0 原始任务说明；继续开发前先阅读 `docs/TASKS.md` 的当前进度。
5. 检查运行与测试报告，验收后再逐个授权 M1–M7。
