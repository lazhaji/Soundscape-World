# Soundscape Railway

移动端声音空间个人作品集。当前实现 **M2：新干线 → 模式与心情 → 到站 → 固定 45° 便利店空间音景**。M1 已由用户确认验收成功；M2 工程与桌面浏览器验证完成，等待用户体验验收。

所有模型、旋律、雨声和列车底噪均为明确标注的项目原创程序化 Demo。无后端、账户、云数据库或 AI。需求以 [PRD](docs/PRD.md) 为准；新 Session 先读 [HANDOFF](docs/HANDOFF.md)。

2026-10-11 新增 **[列车往返运镜 Demo](#/demo/train)**：靠窗 → 停车后穿侧窗 → 固定 45° → 人物下车、列车驶离 → 下一班车接回。晴/多云/小雨与白天/黄昏/夜晚每趟随机。正式入口尚未整合新胶囊；日文广播音频明确待接入。已确认方案和当前边界见 [M2_REDESIGN_SPEC](docs/M2_REDESIGN_SPEC.md)。

## 本地运行

Node.js 22.13+（22.x）或 24.x；依赖精确锁定，本轮未升级依赖。

```bash
npm ci
npm run dev
```

打开终端地址（默认 `http://127.0.0.1:5173/`）：

1. 首次显示新干线车厢，保持静音。点「启程」解锁声音并选择模式；「静音启程」不创建音频上下文。
2. 选择专注、睡眠、放松或自由，单独选择心情与勿扰；可关闭弹窗返回车厢，未确认的选择不会保存。
3. 点「就这样，靠站」，观看约 5 秒减速、开门、穿门、角色自动下车及镜头上摇；也可跳过过场或返回车厢。开启减少动态效果时自动省略大幅运镜。
4. 到站后直接点地面或点「走进店内」，角色绕墙进门，屋顶剖面，音乐渐入；走出店外音乐静音但进度继续。睡眠模式只听雨声。
5. 顶部「声音」打开独立音量/暂停面板；关闭面板不会重启音源。切后台主动暂停，回来后点击继续。
6. 「返回列车」后可以重新选择模式再次到站；同一次页面会话复用一个引擎和三条音源。
7. 刷新后重新回静音列车；上次确认的模式、心情、勿扰由 IndexedDB 预选，仍需主动确认。不能保存时有提示，仍可继续旅程。

主入口为全屏页面；`#/debug/m1` 保留原 M1 验证页，可检查进店/门口/店外、进度和场景重载。两个页面之间通过 Hash 切换，不刷新、不重置音频。

手机联调：`npm run dev -- --host 0.0.0.0`，同局域网访问电脑 IP 与端口。真实设备听感、Safari 行为、后台/锁屏和 GPU 性能需要人工验收。

## 检查与构建

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npm run preview
```

`build` 输出 `dist/`；`preview` 默认仅本机 `http://127.0.0.1:4173/`，相对 base 可用于后续子目录静态部署。直接双击 HTML 不受支持。本轮验收预览用 `npm run preview -- --strictPort --port 4176`；服务停止后可用同一命令恢复。

当前四项检查通过：13 个测试文件 / 64 项测试。正式入口的历史验证及新 Demo 的普通/减少动态往返、触控、天气、音源清理和画面重试证据见 [TEST_PLAN](docs/TEST_PLAN.md)。新 Demo 没有冒充旧版十次循环/GPU 验证；均不等于手机真机或长期内存验收。

## 源码导览

- `src/app/`：全屏主页面、M1 调试页、独立旅程控制器、世界/音频协调与生命周期。
- `src/world/`：列车程序化模型与过场、共用 Canvas、便利店模型、固定相机、角色、碰撞寻路及判区。
- `src/audio/`：应用级单实例引擎、music/rain/train 持续音源、用户/模式/区域串联增益、PCM 合成。
- `src/features/modes.ts`：模式/心情契约、适用音乐过滤及统一社交权限纯函数。
- `src/db/settings.ts`：IndexedDB 设置白名单读写、超时与错误回退；尚无声音档案。
- `src/ui/`：玻璃模式弹窗、可访问模态外壳、声音控制、错误边界。
- `src/demo/train/`：独立运镜预览、纯控制器、镜头路径、天气、临时选择控件和全局声音协调。
- `tests/unit/`、`tests/integration/`：逻辑与生命周期回归；临时浏览器脚本/截图位于被忽略的 `output/playwright/m2-*`。

## 当前边界

- 正式 GLB、录音曲库、雨夜 Shader、随机远处过车尚未加入；参考 PNG/MP4 不是运行时素材。
- M2 只有一首原创器乐 Demo：focus/relax/free 适用，sleep 无候选时回退环境雨声。疲惫/焦虑心情降低旋律强度；DND 不改变音乐。
- 已建立并测试社交权限函数，但雷达/聊天未实现，没有真实在线旅人。完整推荐、导入音乐、计时器属于 M3，档案/备份属于 M4。
- IndexedDB version 1 仅有 settings；无播放统计、Service Worker 或离线缓存。M4 扩表须保留已有设置，不清库。
- 3D 共享分块仍约 920.14 KB / gzip 244.45 KB，有 Vite 500 KB 警告；R3F 内部仍产生 THREE.Clock 弃用警告。本轮不屏蔽警告或修改依赖。
- 真机触控/听感、后台/锁屏、持续帧率与长期 JS 堆待实测；10 次资源计数稳定不是全平台无泄漏证明。

本轮止于 M2，等待用户验收；M3–M7 另行授权，不自动发布或推送。
